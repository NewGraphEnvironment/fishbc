# Planning Files Management

This directory tracks planning-with-files (PWF) artifacts for SRED R&D documentation and knowledge transfer.

## Purpose

PWF files capture the exploration, decision-making, and learning process during complex tasks.

## Directory Structure

```
planning/
  active/           ← Current work-in-progress PWF files
  archive/          ← Completed issues, preserved for reference
```

## Workflow

- `planning/active/` for current PWF work
- Archive to `planning/archive/YYYY-MM-issue-N-description/` when complete
- Key learnings go to CLAUDE.md

**Note:** Planning files are excluded from PRs to upstream (poissonconsulting).
